## Project Description
This project is a GUI-based measurement converter created using Python and PySide6.  
The application allows users to convert:

- Inches to Meters
- Meters to Inches

The program includes:
- Input validation
- Error handling using QMessageBox
- GUI layouts using Qt widgets
- Image display using QPixmap
- Convert, Clear, and Exit functionality
